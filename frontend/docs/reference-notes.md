# Vet Konect reference notes

Source reviewed: https://www.vetkonect.com/ on 2026-08-15.

The current public site exposes a broad Africa-focused navigation including About, Foundation, VetifyPro, Feed Calculator, Disease Predictor, Blog, Chat Forum, Initiatives, and Login. Its homepage highlights animal-care discovery, nearby veterinarian location search, professional and clinic discovery, vendor connection, feed calculation, disease support, and a community forum.

The new VetKonnect Tanzania and Zanzibar experience will retain those service categories while expanding them into a more complete product: verified-profile credentials, paid badge eligibility, role-specific workspaces, medical-record privacy, payment status, notification centre, marketplace inventory, safety messaging, and explicit decision-support disclaimers. This reference is an informational baseline only; the new UI follows the Sunlit Credential design system described in `ideas.md`.
